Text Based Game

Text Based Game is a game for people who like to give orders in plain words.

You tell your crew what to do by typing. The game plays on a tabletop board with miniatures, and a guide suggests what to try. AI turns go through the shared server. You can show the commands or wipe the mill to start over.
